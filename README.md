# Learn Markdown

A small interactive Markdown tutorial with a live practice page.

![Learning Markdown](https://raw.githubusercontent.com/levonium/learning-markdown/master/public/screenshot.jpg)

## Project Setup

```sh
npm install
```

### Development

```sh
npm run dev
```

### Build for Production

```sh
npm run build
npm run preview
```

### Code Quality

```sh
npm run lint
npm run format
npm run test
```
